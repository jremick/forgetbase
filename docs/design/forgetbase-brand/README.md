# ForgetBase Brand Options

ForgetBase is the app-facing name for the agent-native instruction control plane. The identity should feel precise, governed, and operational: a base of retained instructions and knowledge, with explicit controls for what is recalled, withheld, released, or forgotten.

## Palette

- Primary: `#1d5a80`
- Deep: `#154a6a`
- Tint: `#d7e6f0`
- White: `#ffffff`

The palette intentionally stays close to the current app design system so the logo can land without a larger UI reskin.

## Options

| Option | File | Rationale |
|---|---|---|
| 01 Notch | `marks/01-notch.svg` | A stable base with one removed corner; strong small-size metaphor for governed forgetting. |
| 02 Strata | `marks/02-strata.svg` | Layered knowledge records with one released layer, useful for corpus/versioning language. |
| 03 Aperture | `marks/03-aperture.svg` | Permission-scoped recall through a controlled opening into the base. |
| 04 Redaction | `marks/04-redaction.svg` | Explicit policy and withheld content, best for security-heavy positioning. |
| 05 Monogram | `marks/05-monogram.svg` | A compact FB monogram that keeps the name visible, but is more conventional. |
| 06 Datum | `marks/06-datum.svg` | Provenance and baseline accuracy, good for eval/citation-heavy messaging. |
| 07 Boundary | `marks/07-boundary.svg` | Permission boundary with one controlled release edge. |
| 08 Keystone | `marks/08-keystone.svg` | A removed keystone from a stable base, strong for governance architecture. |
| 09 Dissolve | `marks/09-dissolve.svg` | Retention policy shown as controlled dissolution; selected for the app mark because it makes forgetting feel active and governed. |
| 10 Partition | `marks/10-partition.svg` | Retained and released halves of the same governed base. |

## Recommended Shortlist

1. `09-dissolve.svg` - selected app mark; strongest expression of governed retention and deletion as an active product capability.
2. `01-notch.svg` - cleanest small-size fallback if the dissolve fragments feel too busy in production.
3. `08-keystone.svg` - strongest enterprise/governance metaphor if the brand wants to feel more architectural.

The current app favicon and lockup use `favicon-forgetbase.svg`, derived from option 09.
